# 用户使用指南

## 1. 安装

1. 双击 `LocalVoiceInput-Setup-x64.exe`。
2. 按向导完成安装（默认安装到 `%LOCALAPPDATA%\Programs\LocalVoiceInput`，**不需要管理员权限**）。
3. 勾选“启动”或从开始菜单/桌面快捷方式启动。
4. 首次启动按引导选择麦克风、检查权限、设置快捷键、试说一段、选择默认模式。

安装包已内置 Python 运行时、native DLL、流式 ASR、复核 ASR、LLM、llama.cpp 与模型，
**不需要**安装 Python、.NET、VC++、CUDA、ONNX Runtime、llama.cpp、Ollama、FFmpeg、Git 或任何模型。

## 2. 第一次使用

1. 把光标放进任意可输入文字的输入框（微信、浏览器、Word、VS Code、记事本等）。
2. **按住 `F9`** 说话，松开。
3. 极速模式下文字会直接插入；屏幕底部悬浮窗显示实时识别。

- 录音中按 `Esc` 取消。
- 悬浮窗可拖动，位置会记住。
- 托盘图标颜色：灰=待机、红=录音、黄=处理中。

## 3. 三种模式

| 模式 | 行为 | 适用 |
|---|---|---|
| 极速输入 | 片段结束即插入，不调用 LLM | 聊天、搜索、短文本、IDE |
| 智能精修 | 结束后打开对照面板，确认后插入 | 长口述、笔记、文档草稿 |
| 自动 | 短句极速；超过阈值后转为精修确认 | 不确定场景 |

切换：托盘菜单 →「输入模式」，或设置 → 常规 → 默认模式。

## 4. 悬浮窗

- 状态圆点 / 当前模式 / 声音电平。
- 已稳定文字（亮色）与未稳定文字（灰色）区分。
- 按钮：**停止 / 提交 / 精修 / 取消**；目标变化时显示 **重试插入 / 复制 / 取消**。
- 录音中点「精修」会把本次会话切到确认模式，不会自动改写已说的内容。

## 5. 精修面板

- 左侧片段列表；右侧「精修 / 原文」切换，可直接编辑。
- **插入到原窗口**：恢复到录音开始时的窗口后插入；不会插到当前焦点。
- **复制**：复制待插入文本。
- **重新识别**：用复核模型重新识别当前片段（需要该片段音频）。
- **重新精修 / 精修选中 / 深度整理**：调用本地 LLM；深度整理仅在点击时执行。
- **差异对照**：左右显示原文/精修，红色为删除、绿色为新增；支持逐条接受/拒绝 LLM 修改。
- **恢复原文**：清空手动修改，回到确定性整理结果。
- 失败/超时：保留原文并显示原因，不会清空。

## 6. 设置

托盘 → 设置…（或 `LocalVoiceInput.exe --settings`）：

1. **常规**：模式、主题、悬浮窗、开机自启。
2. **麦克风与音频**：设备、自动检测、端点静音、片段长度、无语音自动停止、麦克风测试。
3. **语音识别**：流式模型路径、线程、复核策略/超时、模型校验。
4. **智能精修**：开关、档位、预加载、线程、超时、空闲卸载、精修测试。
5. **专业词库**：错词→正确写法、受保护术语、CSV 导入导出。
6. **快捷键**：按住说话、连续听写、提交、撤销、取消。
7. **历史记录**：查看/复制/清空，是否保存。
8. **性能与诊断**：模型状态、内存、路径、版本、加载测试、SHA-256 校验。

保存后热键/模型等需要「保存并重启」生效。

## 7. 快捷键

| 功能 | 默认 | 说明 |
|---|---|---|
| 按住说话 | `F9` | 松开结束 |
| 连续听写 | `F10` | 按一下开始，再按停止 |
| 取消 | `Esc` | 录音中丢弃 |
| 提交/确认 | `Ctrl+Enter` | 精修面板确认插入 |
| 撤销上屏 | `Ctrl+Alt+Z` | 60 秒内，用户显式触发 |

全部可在设置 → 快捷键中重新捕获。

## 8. 隐私

- 录音、识别、精修全部在本机完成；不联网、不上传。
- 默认不保存音频；历史仅保存在本机 SQLite。
- 日志不含原始录音。
- 不读取目标应用的其他内容，只记录窗口句柄/进程/标题用于安全插入。

## 9. 常见问题

**按热键没反应？**
- 确认程序在托盘运行；
- 目标窗口若以管理员权限运行，Windows 不允许普通进程向它发送按键；请以管理员身份运行本程序。

**没有插入文字？**
- 看悬浮窗是否提示“目标已变化”；
- 文本会保留，可点「复制」或「重试插入」；
- 部分终端/游戏不接受剪贴板粘贴或 Unicode 直输，请换用普通编辑框验证。

**中文没上屏 / 乱码？**
- 默认使用剪贴板粘贴；若剪贴板含图片等无法安全恢复的格式，程序会自动改用 Unicode 直输，原剪贴板保留。

**麦克风打不开？**
- Windows 设置 → 隐私和安全性 → 麦克风 → 允许桌面应用访问；
- 设置 → 麦克风与音频 → 自动检测。

**模型加载失败？**
- 设置 → 性能与诊断 → 校验模型；或运行 `LocalVoiceInput.exe --diagnose`；
- 不要移动/删除安装目录下的 `models`。

**想完全卸载？**
- 设置 → 应用 → 本地语音输入 → 卸载；
- 用户数据（配置/历史/日志）保留在 `%LOCALAPPDATA%\LocalVoiceInput`，如需彻底清除请手动删除该目录。

## 10. 更新

- 托盘 →「检查更新…」：读取签名更新清单，发现新版本后下载并校验 SHA-256，再提示退出安装。
- 增量更新包不含模型，复用已安装的 `models\`；模型集不匹配会要求安装完整包。
- 便携版不自动安装更新，请下载新的 Portable ZIP 替换。
- 更新检查只在用户点击时联网；核心识别/精修仍然完全离线。
