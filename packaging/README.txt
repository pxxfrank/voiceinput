voiceinput · 离线语音输入法（便携版 / Windows x64）
=================================================

用法
----
1. 双击 voiceinput.exe —— 后台常驻，右下角托盘出现麦克风图标（无窗口、无控制台）。
2. 把光标放到任意输入框，按住 F9 说话，松开后文字直接出现在光标处，同时屏幕底部
   的悬浮字幕窗实时显示字幕。
3. 连续听写：按一下 F10 开始持续录音（字幕持续显示），再按一下停止并把整段文字上屏。
   字幕窗底部会提示「按 F10 停止 · Esc 取消」。
4. 一句话超过字幕宽度会自动换行（多行显示），上一句始终保留在最上面。
5. 录音中按 Esc 可丢弃本次；按 Ctrl+Alt+Z 撤销上一次上屏。
6. 退出：右键托盘图标 ->「退出」。

首次使用
--------
- 若默认麦克风不对：右键托盘 ->「设置…」-> 麦克风「自动检测」，对着麦克风说几句话即可自动选中。
- 字幕显示方式 / 字号：右键托盘 ->「字幕」/「字幕大小」；字幕可鼠标拖动到任意位置。
- 其它设置：右键托盘 ->「设置…」。

隐私
----
完全离线：识别全部在本机完成，不产生任何网络请求；音频只在内存中处理。

目录
----
  voiceinput.exe   主程序
  _internal\       运行库（请勿删除）
  models\          本地 ASR 模型（请勿删除）
  config.yaml      配置
  voiceinput.log   运行日志（无控制台时用于排查）

说明：本包内含 int8 量化模型（SenseVoice-Small，约 240MB），即程序实际加载的权重，
      因此开箱即用、无需联网。若想换成 Paraformer 或更高精度模型，可在设置界面「关于」页下载切换。
